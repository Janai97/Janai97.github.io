# Databases

## Overview

This section demonstrates my experience working with databases and developing applications that interact with stored data. The featured artifact is my Animal Shelter Dashboard project from CS 340.

## Featured Artifact

### Animal Shelter Dashboard

The Animal Shelter Dashboard is a database-driven application that uses MongoDB to store and manage animal records.

The application provides functionality for interacting with the database and performing operations such as creating, reading, updating, and deleting records.

## Why I Selected This Artifact

I selected this artifact because it demonstrates my experience working with a database as part of a larger application.

The project required me to understand how application code communicates with a database and how information can be organized so that it can be accessed and modified when needed.

## Improvements

I identified several areas where the original application could be improved. These included improving filtering and search functionality, making updates easier to perform, improving the way information is displayed, and organizing database interactions more effectively.

These improvements would make the application easier to use while also creating a more organized approach to working with the database.

## Reflection

Working on this project helped me understand the relationship between an application and the database supporting it. I learned that database design and organization have a direct effect on the usability and performance of an application.

The project also gave me practical experience working with MongoDB and CRUD operations, which are skills I can carry into future software development projects.
