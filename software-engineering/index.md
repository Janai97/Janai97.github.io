# Software Design & Engineering

## Overview

This section of my ePortfolio demonstrates my ability to apply software engineering principles to the design and development of software applications. The artifact selected for this section comes from my work in CS 330: Computational Graphics and Visualization.

## Featured Artifact

### CS 330 Computational Graphics and Visualization

For this artifact, I developed a 3D scene using C++ and OpenGL. The project required me to work with multiple graphical elements and apply concepts such as object construction, lighting, materials, textures, and scene organization.

The project demonstrates my ability to work with an existing codebase while expanding its functionality and improving the organization of the application.

## Why I Selected This Artifact

I selected this project because it demonstrates several areas of software engineering that are important to my development as a programmer. It required me to think about how different parts of a program interact with one another while also considering organization, readability, and functionality.

Working on the project also gave me experience troubleshooting problems within a larger application. This helped me become more comfortable identifying issues, testing possible solutions, and making changes without disrupting other parts of the program.

## Improvements

The original artifact provided a strong foundation, but there were areas where I could improve the organization and functionality of the project. My enhancements focused on improving the structure of the application and demonstrating a stronger understanding of software development principles.

The final version represents my growth in working with more complex software and applying concepts that can be carried into future development projects.

## Reflection

This project helped me understand that software development involves more than simply writing code that works. The way code is organized, maintained, tested, and expanded is equally important.

Through this project, I became more comfortable working with a larger codebase and troubleshooting problems that were not always immediately obvious. These experiences have helped prepare me for future software engineering work.
